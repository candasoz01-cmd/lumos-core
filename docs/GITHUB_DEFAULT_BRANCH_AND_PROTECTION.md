# GitHub: default branch ve koruma

**Default branch nerede:** Repo **Settings → General** sayfasında, en üstte **Default branch** bölümü var (Branches sayfası değil). Oradan hangi branch’in varsayılan olduğunu görüp değiştirebilirsin. **Branch protection** kuralları ise **Settings → Branches → Branch protection rules** altında; “Allow deletions” kapalıysa branch silinmesi engellenir. Private repo’da bazı korumalar plan/organizasyon yüzünden “Not enforced” uyarısı verebilir; böyle durumda korumayı yerel disiplin ve PR akışıyla yönetmek yeterli.
