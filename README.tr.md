### Katman A (~5 dk)

Yalnızca arayüz; köprü gerekmez. Sınırlı mod **normaldir**.

```bash
cd lumos-core/ui
npm install
npm run dev
```

- Landing: http://127.0.0.1:4321/
- Panel: http://127.0.0.1:4321/panel
